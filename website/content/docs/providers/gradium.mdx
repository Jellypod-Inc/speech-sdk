## Usage

```ts
import { generateSpeech } from "@speech-sdk/core"

const result = await generateSpeech({
  model: "gradium/gradium-tts-beta",
  text: "Hello from SpeechSDK!",
  voice: "your-gradium-voice-id",
})
```

The beta is opt-in. The SDK retains `default` for bare `gradium` calls.
